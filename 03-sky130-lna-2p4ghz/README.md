# CMOS LNA SKY130

2.4 GHz CMOS Low-Noise Amplifier designed using the SKY130A PDK.

## Files

- `schematic/lna_bw300.sch` — LNA schematic
- `schematic/lna_q8_m4.sch` — Q8/M4 version
- `schematic/corner-schematics/` — FF, SS and TT corner schematics at different temperatures
- `simulation/lna_twotone_final.sch` — two-tone simulation
