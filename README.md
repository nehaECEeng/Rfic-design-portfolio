# RF and Analog IC Design Portfolio

This portfolio contains RF, microwave, antenna, and analog IC design projects using Qucs-S, Keysight ADS, ANSYS HFSS, and the SKY130A process.

| No. | Project | Description |
|---|---|---|
| 01 | [BJT Common-Base Characterization](01-bjt-common-base-qucs/README.md) | Qucs-S input and output characteristics of a BC547C in common-base configuration. |
| 02 | [BJT Common-Emitter Characterization](02-bjt-common-emitter-qucs/README.md) | Qucs-S characterization of a BC547C in common-emitter configuration. |
| 03 | [SKY130 CMOS LNA](03-sky130-lna-2p4ghz/README.md) | A 2.4 GHz low-noise amplifier designed with the SKY130A PDK. |
| 04 | [BFP740F SiGe LNA](04-bfp740f-sige-lna-2p4ghz/README.md) | A 2.4 GHz common-emitter LNA with ADS matching, stability, noise, and two-tone analysis. |
| 05 | [PIN-Diode RF Switches](05-pin-diode-rf-switch-ads/README.md) | PIN-diode models, DC characterization, and RF switch configurations in ADS. |
| 06 | [Coupled-Line Bandpass Filter](06-coupled-line-bandpass-filter-2p4ghz-ads/README.md) | A 2.4 GHz edge-coupled microstrip filter studied with ADS circuit models. |
| 07 | [Implantable MIMO Antennas](07-implantable-mimo-antennas-hfss/README.md) | Two-port implantable MIMO antenna designs at 2.45 GHz and 3.6 GHz using ANSYS HFSS. |
| 08 | [NB-IoT Slotted MIMO Antenna](08-nbiot-slotted-mimo-antenna-hfss/README.md) | NB-IoT slotted MIMO antenna design and simulation using ANSYS HFSS. |
| 09 | [SKY130 Gilbert Mixer](09-sky130-gilbert-mixer-rfic/README.md) | A SKY130 RFIC Gilbert-cell mixer with bias design, conversion-gain, noise, and linearity simulations. |
| 10 | [SKY130 Analog IC Design](10-sky130-analog-ic-design/README.md) | A complementary-input, two-stage CMOS OTA designed with SKY130A models and simulated using ngspice. |
